* What to try

Move the start month: pay shrinks for both, but the recruiter fee and setup do
not, so a late start favors the contractor. The break-even rate is the hourly
rate at which a contractor working these hours costs the same as an employee for
a full year, before one-time costs.

Finance's rates for benefits and payroll tax, equipment, working weeks and the
recruiter fee come from a pinned shared input, so every team's model uses the
same numbers. They show under *Shared inputs* and cannot be given controls here.
This example's inline CID holds load=0.3, laptop=2500, weeks=46 and fee=0.2, so
it works offline; a real model would paste the CID of finance's saved
assumptions document.
